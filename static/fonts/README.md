# Polices

Polices variables auto-hébergées (sous-ensemble latin), pour que le site fonctionne hors ligne.
Toutes sont distribuées sous licence SIL Open Font License 1.1.

| Fichier | Police | Usage |
| --- | --- | --- |
| `bricolage-grotesque.woff2` | Bricolage Grotesque (Mathieu Triay) | titres |
| `instrument-sans.woff2` | Instrument Sans (Rodrigo Fuenzalida, Jordan Egstad) | texte |
| `jetbrains-mono.woff2` | JetBrains Mono (JetBrains) | chiffres, code, étiquettes |

Source des fichiers : paquets `@fontsource-variable/*`.
