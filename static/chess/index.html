Comment ça marche

L'IA utilise l'algorithme Alpha-Beta pour explorer l'arbre des coups possibles et choisir le meilleur coup.

Votre rôle : écrivez la fonction evaluate(board) en Python qui évalue une position. Un score positif favorise les blancs, négatif les noirs.

Alpha-Beta : amélioration du Minimax qui "coupe" les branches inutiles de l'arbre de recherche, réduisant le nombre de positions à évaluer.

Arbre : en dessous, visualisez l'arbre de recherche complet avec les valeurs alpha/beta et les coupures.
